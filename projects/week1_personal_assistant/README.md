# Week 1 项目：智能个人助手

## 项目简介

一个基于LangChain的智能个人助手，集成多种功能工具，能够帮助用户处理日常任务。

## 功能特性

- 📅 日程管理：添加、查询、删除日程
- 🌤️ 天气查询：获取城市天气信息
- 🧮 计算器：执行数学计算
- 📝 备忘录：记录和查询备忘事项
- 💬 自然对话：理解用户意图，智能选择工具

## 技术栈

- LangChain：Agent框架
- OpenAI GPT：大语言模型
- Python：开发语言

## 快速开始

### 1. 安装依赖
```bash
cd projects/week1_personal_assistant
pip install -r requirements.txt
```

### 2. 配置环境变量
```bash
cp .env.example .env
# 编辑.env文件，填入OpenAI API密钥
```

### 3. 运行项目
```bash
python main.py
```

## 常见问题

### Q: Agent总是选错工具怎么办？
A: 优化工具的description，让描述更清晰准确。

### Q: 如何减少API调用成本？
A: 使用缓存、选择合适的模型（GPT-3.5 vs GPT-4）。

### Q: 工具调用失败如何处理？
A: 添加try-catch错误处理，返回友好的错误信息。
